    Connect Firebase

    1. In the Firebase console, create a project and add Firestore Database in production or test mode.
    2. Under Project settings, register a Web app and copy the firebaseConfig object.
    3. Paste it below and press Connect. The page reloads and syncs live.
    4. In Firestore, open the Rules tab, paste the rules below and press Publish. This tracker has no sign-in, so these rules allow access without one. Anyone who has your Firebase config can read and write this collection, so keep the config private.
    rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /jobApplications/{id} { allow read, write: if true; } } }

    Keep this connection permanently

    The config is currently kept in this browser, so clearing site data removes it. Save it into the file itself and it stays, even on a fresh browser.

    Replace your current file with the downloaded one. Or paste the copied line over var FIREBASE_CONFIG = null; near the top of the script in your file.

    Download everything as JSON, or restore from a file you exported earlier.
